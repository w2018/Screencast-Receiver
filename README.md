# 投屏助手 (ScreenCast Receiver)

Windows 桌面 DLNA 投屏接收端，MPV 内核播放。**版本：v1.3.3**

## 功能特性

| 功能 | 说明 |
|------|------|
| 🖥️ **DLNA 投屏接收** | 手机（微信/爱奇艺/B 站/腾讯视频等）投屏，自动播放 |
| 🔐 **投屏授权确认** | 收到请求弹允许/拒绝窗口，显示设备名/IP/视频地址 |
| 🎬 **视频播放** | MPV 内核，支持本地文件 / HTTP / HLS / RTSP |
| ⏯ **播放控制** | 播放/暂停/停止/进度跳转/倍速(0.5-2.0x)/音量/静音 |
| 🔄 **镜像翻转** | 水平/垂直镜像 |
| ⏮️ **进度记忆** | 自动记忆进度，可续播 |
| 🎛️ **自定义快捷键** | 窗口 + 全局快捷键 |
| 🗂️ **系统托盘** | 关闭最小化到托盘，后台常驻 |
| ⚙️ **完整设置** | 开机自启/设备名/硬件解码/网络缓冲等 |
| 🔌 **单实例** | 重复启动聚焦已有窗口 |
| 🌐 **网络视频播放** | URL 直接播放，扫码远程控制，播放历史 |
| ⚡ **DLNA 设置实时生效** | 开关/设备名改动无需重启 |

## 技术栈

- **Rust + Tauri 2**：桌面外壳
- **libmpv**（`tauri-plugin-libmpv`）：视频解码渲染
- **React 18 + TypeScript + Vite + Zustand**：前端
- **rusqlite**：配置与进度持久化（SQLite）

## 安装

1. 从 [Releases](https://github.com/w2018/Screencast-Receiver/releases) 下载 `投屏助手_1.3.3_x64-setup.exe`
2. 运行安装（默认安装到 `D:\投屏助手`，无需管理员权限）
3. 从桌面/开始菜单启动

> 安装包已内置 `libmpv-2.dll` 与 `libmpv-wrapper.dll`。

## 使用说明

### 投屏（DLNA）
1. 手机与电脑同一 Wi-Fi
2. 手机视频 App 点"投屏"
3. 选择设备 **投屏助手**（设备名可在设置自定义）
4. 电脑弹授权确认 → 点"允许"
5. 视频自动播放，手机可控制

### 播放控制
- `Space` 播放/暂停 · `←`/`→` 快退快进 5 秒
- `↑`/`↓` 音量 · `M` 静音 · `F` 全屏 · `C` 镜像

### 网络视频播放
- 控制栏 🌐 打开对话框，输入 URL（HTTP / HLS / RTSP）直接播放
- 扫码远程控制：手机扫码后浏览器远程发送地址/控制
- 播放历史：自动记录，可重播或删除

### 设置
- 控制栏 ⚙ 打开设置面板（通用/播放/快捷键/网络）

## 网络与设备发现

- **DLNA 协议**：UPnP MediaRenderer，SSDP NOTIFY alive + 响应搜索
- **多网卡兼容**：枚举 IPv4 网卡并过滤虚拟网卡（Hyper-V 等），加入组播组
- **设备 UUID 持久化**：首次生成落盘，改名仅更新友好名
- **DLNA 设置实时生效**：开关/设备名改动自动重启 SSDP 服务
- **固定端口**：DLNA HTTP 监听 TCP 1900（与 UDP 1900 一致，便于防火墙放行）

### 手机扫不到设备排查
1. 确认同一 Wi-Fi（设置可看 DLNA 监听 IP）
2. 防火墙放行：设置 → 网络 → 复制防火墙命令 → 管理员命令行执行
3. 仍不行检查路由器 AP/客户端隔离

## 数据与日志

- 配置与播放记录：`{安装目录}/config/screencast.db`
- 日志：`{安装目录}/log/`

## 已知问题

- 仅支持 **DLNA/UPnP**（AirPlay、Miracast 暂未支持）
- 部分 App 使用私有协议而非标准 DLNA 时无法发现（B 站、阿里云盘等标准 DLNA 正常）
- DLNA 仅单路会话
- 硬件解码（D3D11VA）个别显卡可能异常，可在设置关闭
