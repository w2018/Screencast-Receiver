# 投屏助手 (ScreenCast Receiver)

> Windows 桌面投屏接收端 —— 接收手机/设备的 DLNA 投屏，用 MPV 内核播放。
> **版本：v1.1.0**

## 功能特性

| 功能 | 说明 |
|------|------|
| 🖥️ **DLNA 投屏接收** | 手机（微信/爱奇艺/B 站/腾讯视频等）投屏到本应用，自动播放 |
| 🔐 **投屏授权确认** | 收到投屏请求弹出允许/拒绝窗口，显示设备名称/IP/视频地址 |
| 🎬 **视频播放** | MPV 内核，支持本地文件 / HTTP / HLS / RTSP 网络流 |
| ⏯ **播放控制** | 播放/暂停/停止/进度跳转/倍速(0.5-2.0x)/音量/静音 |
| 🔄 **镜像翻转** | 水平/垂直镜像（投屏画面矫正） |
| ⏮️ **进度记忆** | 自动记忆播放进度，重新打开可续播 |
| 🎛️ **自定义快捷键** | 窗口快捷键 + 全局快捷键，可自定义 |
| 🗂️ **系统托盘** | 关闭最小化到托盘，后台常驻；投屏请求自动唤醒弹窗 |
| ⚙️ **完整设置** | 开机自启/设备名称/硬件解码/网络缓冲等，即时保存 + 保存提示 |
| 🔌 **单实例** | 重复启动自动聚焦已有窗口，不会多开 |

## 技术栈

- **Rust + Tauri 2**：桌面外壳
- **libmpv**（`tauri-plugin-libmpv`）：视频解码渲染
- **React 18 + TypeScript + Vite + Zustand**：前端
- **rusqlite**：配置与进度持久化（SQLite）

## 安装

1. 从 [Releases](https://github.com/w2018/Screencast-Receiver/releases) 下载最新 `投屏助手_1.1.0_x64-setup.exe`
2. 运行安装程序（默认安装到 `D:\投屏助手`，无需管理员权限）
3. 安装完成后从桌面/开始菜单启动

> 安装包已内置 `libmpv-2.dll` 与 `libmpv-wrapper.dll`，无需额外配置。

## 使用说明

### 投屏（DLNA）
1. 确保手机与电脑在**同一 Wi-Fi 局域网**
2. 手机打开视频 App（微信、爱奇艺、B 站等），点击"投屏"
3. 在设备列表中选择 **投屏助手**（设备名称可在设置中自定义）
4. 电脑弹出**投屏授权确认**窗口 → 点"允许"
5. 视频自动播放，手机端可控制播放/暂停/进度/音量

### 播放控制
- `Space` 播放/暂停 · `←`/`→` 快退/快进 5 秒
- `↑`/`↓` 音量调节 · `M` 静音 · `F` 全屏 · `C` 镜像
- 播放控制栏：进度条拖拽、倍速菜单、音量、全屏

### 设置
- 点击控制栏 ⚙ 打开设置面板（通用/播放/快捷键/网络 四类，改动即时生效 + 提示）

## 网络与设备发现

- **DLNA 协议**：UPnP MediaRenderer，SSDP 主动宣告（NOTIFY alive）+ 响应搜索
- **多网卡兼容**：自动枚举所有 IPv4 网卡加入组播组（解决多网卡机器手机扫描不到的问题）
- **随机端口**：DLNA HTTP 服务随机监听空闲端口，设置面板显示当前绑定 IP:端口

### 手机扫描不到设备时的排查
1. 确认手机与电脑在**同一 Wi-Fi**（可在设置面板查看 DLNA 监听 IP）
2. **放行防火墙**：设置面板 → 网络 → 复制防火墙命令 → 以管理员身份在命令行执行
3. 若仍扫不到，检查路由器是否开启"AP 隔离/客户端隔离"

## 数据与日志

- **配置与播放记录**：`{安装目录}/config/screencast.db`
- **日志**：`{安装目录}/log/`

## 已知问题 / 限制

- 当前仅支持 **DLNA/UPnP** 投屏协议（AirPlay、Miracast 为规划中功能）
- 部分 App（如 B 站）投屏可能使用自有私有协议，非标准 DLNA 时无法发现
- DLNA 仅支持单路投屏会话
- 硬件解码（D3D11VA）在极个别显卡可能异常，可在设置中关闭
