**🔧 关键问题修复：播放黑屏（只有声音无画面）**

> **现象**：播放有声音但画面黑屏（用户反馈 2026-08-14）。
> **根因**：`VideoSurface` div 的背景为不透明黑色 `background: #000`。MPV 通过 wid 嵌入渲染在窗口最底层，该不透明 div 完全遮挡了 MPV 画面。
> **修复**：`App.css` 中 `.video-surface` 背景改为 `background: transparent`，让 MPV 画面透出。
> **验证**：用户确认画面恢复正常 ✅
> **经验**：嵌入 wid 的视频播放器（MPV），前端覆盖层背景必须透明，否则必然遮挡画面。

## 用户反馈修复（第六轮）—— 设备扫描不到根因

**根因**：多网卡机器（WLAN + VMware + Tailscale + WSL）上，SSDP 组播加入用的是默认接口（`0.0.0.0`），只加入了 Tailscale/WSL 等接口，**WLAN 接口未加入组播组** → 手机在 WLAN 发出的 M-SEARCH 组播收不到 → 设备无法被发现。

**修复**：使用 `local-ip-address` crate 枚举所有 IPv4 接口，**逐个调用 `join_multicast_v4`**。实测加入接口：`192.168.2.233(WLAN), 127.0.0.1, 10.0.0.5, 192.168.137.1, ...` ✅

**验证**：组播 M-SEARCH 响应正常（LOCATION 指向 WLAN IP），WLAN 接口已加入组播组。

**最终产物（第六轮）**：`投屏助手_0.1.0_x64-setup.exe`（32.03MB）
